# Code of Conduct

## The short version

Be decent. Argue about code, not about people.

## The standard

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it is short and it says what you would expect.

## Reporting

Report unacceptable behaviour to the maintainer at the address on
[github.com/pratikbin](https://github.com/pratikbin), or privately through
[GitHub Security Advisories](https://github.com/pratikbin/opensecretmask/security/advisories/new)
if you would rather it stay out of public view.

Reports are handled privately. A maintainer involved in an incident does not
decide its outcome.
